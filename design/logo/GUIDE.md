# 世界色彩地球 · 标志使用说明

**创意：**给地球上的一格涂上颜色。实心和斜线两种填法，正是这个应用的两种涂色样式。

## 文件

| 文件夹 | 内容 |
|---|---|
| `symbol/` | 图形标志：彩色、深色背景用、黑、白（反白，线条细 0.6 单位）、单色蓝；`small-` 开头的是 32 像素以下用的加粗版 |
| `lockup/` | 横排和竖排组合，各有彩色、深色背景用、黑、白四种 |
| `icon/` | macOS 应用图标 `AppIcon.icns`、它的源图和 iconset |
| `web/` | `favicon.svg`（随浏览器明暗主题变色）、`favicon.ico`、苹果触屏图标、192/512 图标和 `site.webmanifest` |
| `png/` | 以上标志的透明 PNG，图形 64–1024 像素，组合 1200 像素宽 |

全部在 `kit/` 里，由 `build-kit.mjs` 生成（`node design/logo/build-kit.mjs && node design/logo/export.mjs`），改形状或颜色时改脚本，不要手改 SVG。

## 颜色

| 用途 | 浅色背景 | 深色背景 |
|---|---|---|
| 线条（墨） | `#1d2330` · RGB 29 35 48 · CMYK 约 40 27 0 81 | `#e8eaef` |
| 涂色（蓝） | `#2c559b` · RGB 44 85 155 · CMYK 约 72 45 0 39 | `#93b2e8` |
| 英文小字 | `#5d6675` | `#9aa3b2` |

和应用界面的主色、文字色一致。CMYK 是换算值，印刷前要打样；专色还没有选。灰度下两块涂色靠“实心”和“斜线”区分，不靠色相，所以黑白版照样成立。

## 字体

中文字标用 Noto Sans SC Medium，英文小字用 IBM Plex Sans Medium，字间距 0.16 em，两者都是 SIL Open Font License，允许用在标志里。文件里的字已经转成路径，不依赖电脑上装的字体。

## 留白和最小尺寸

- 四周至少留出球体直径的 1/4（相当于 256 网格上的 54 个单位）。
- 图形标志：48 像素以上用常规版；16–32 像素用 `small-` 版。印刷最小 6 mm。
- 横排组合：宽度不小于 160 像素（印刷 30 mm）。竖排组合：宽度不小于 120 像素，再小时去掉英文小字或改用图形标志。

## 背景

- 浅色背景（白、地图的纸色 `#fbfaf7`、界面底色 `#eef0f3`）用彩色版。
- 深色背景（界面深色 `#14171d`）用 `color-dark` 版；照片或花纹上用白色版。
- 不要放在和涂色蓝接近的中蓝色上，蓝色那一格会消失；这时用白色版。

## 不要这样用

- 拉伸、旋转、加阴影、加描边或渐变。
- 只换其中一种颜色，或把斜线改成别的方向。斜线向右上倾斜 45°，和应用里一致。
- 改字标的字体、字距，或把中文和图形的相对大小、间距改掉。
- 在标志上画真实的国界或大陆轮廓。

## 交付说明

- 形状用多边形运算生成，再把落在圆和椭圆上的边写回成弧线，主文件里没有文字、遮罩、滤镜和描边。技能自带的 `svg_audit.py` 检查结果：8 个图形标志都是 100 分；组合版因为中文字形锚点多，被提示“复杂”，属于正常情况。
- 应用图标是普通 `.icns`，按 macOS 的圆角网格（1024 画布、824 圆角方块）画。没有用 Icon Composer，所以没有深色和着色版本；在 macOS 26 以后的系统上，系统可能会把它放进统一的底板，需要在真机上看一下。
- 商标是否可以注册和使用，没有做过检索，正式使用前建议查一下商标数据库，并做一次以图搜图。
