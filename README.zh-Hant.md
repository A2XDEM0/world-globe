# 世界色彩地球 · World Color Globe

[简体中文](README.md) · **繁體中文** · [English](README.en.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Español](README.es.md)

一個可以拖曳旋轉、縮放的世界地球，能按國家、一級行政區（省、州）或二級行政區（市、縣）分別上色，點國家可以開啟它的平面地圖。有網頁版和 macOS 桌面版，兩者共用同一份前端程式碼。介面支援簡體中文和英文。

![地球檢視：範例配色，塗了加拿大、巴西、墨西哥等國](docs/images/globe.jpg)

## 能做什麼

### 轉、找、放大

拖曳可以旋轉，有慣性；滾輪、雙指或右上角的按鈕可以縮放，最大 10 倍。方向鍵也能旋轉，Enter 會對畫面正中央的國家執行目前的操作。

頂部的搜尋框可以輸入中文名、英文名或三位代碼。選中後，地球會轉到這個國家的首都，並放大到整個國家大致佔滿畫面。這裡只算首都所在的那片國土，以及離首都不比本土最遠處遠太多的島嶼，所以美國不算阿拉斯加，丹麥不算格陵蘭。梵蒂岡、新加坡這樣的小國會直接放大到 10 倍；距離較遠時，途中會先拉遠再拉近。

![搜尋「日本」後，地球轉到東京並放大到整個日本](docs/images/search.jpg)

### 塗色

頂部有「塗色 / 查看」兩種模式，以及「國家 / 一級 / 二級」三種塗色單位。塗色模式下，點一下為目前的單位上色，再點一次取消。選一級或二級時，滑鼠停在國家上會顯示它的行政區界線，以及所指區域的名稱和代碼。不管目前用的是哪支畫筆，按住 Option（Windows 上是 Alt）點擊，都會把這個單位直接還原。

每種顏色可以設定名稱、純色或斜線、色碼，行政區的顏色會蓋過國家的顏色。右側可以直接輸入國家名或行政區代碼來批次上色，找不到的項目會另外列出。

二級行政區的代碼是「國家代碼-編號」，例如芝加哥所在的庫克郡是 `USA-0628`。編號在每個國家內按名稱排序產生，底層資料不變，代碼就不會變。全世界共 49,340 個，沒有重複。一級行政區的代碼寫成 `USA.US-CA` 這樣。

### 平面圖

查看模式下點國家，會開啟它的平面圖。美國用 Albers USA 投影，附阿拉斯加和夏威夷插圖；其他國家用依國家範圍自動設定參數的 Albers 等積圓錐投影，南極洲用極地等積投影。遠離本土的領土放進底部的小插圖，最多 6 個；中國平面圖右下角有南海小圖。平面圖最大可以放大 12 倍，放大後會顯示更多行政區名稱。

下圖為德國東部 7 個一級行政區單獨上了色。德國的行政區沿 1951–1990 年的東西德分界線對齊過，塗色邊緣正好落在分界線上，柏林也拆成了西柏林和東柏林。

![德國平面圖：東部各邦塗成藍色，邊緣沿東西德分界線](docs/images/germany.jpg)

### 陣營和國旗

右側「陣營」裡可以勾選歐盟、北約、華約、集體安全條約組織、東協、石油輸出國組織、美洲國家組織和不結盟運動。勾選的陣營會在地圖上疊一層斜紋，同屬幾個陣營的國家各色輪流出現。展開可以看成員的國旗、成員狀態和已退出的成員，還能一鍵把成員塗成目前的顏色。華約按當年的地域顯示：蘇聯取 15 個繼承國，東德取德國東部各邦。

![歐洲：北約（青綠斜紋）和華約（紅色斜紋）疊加顯示](docs/images/blocs.jpg)

### 中英文和主題

頂欄可以切換中文和英文，按鈕、提示、國家名、行政區名、平面圖標註和匯出的圖都會跟著換。「底圖」裡可以選跟隨系統、淺色或深色主題。主題只改介面，不改地圖本身的顏色。

![英文介面加深色主題，地球轉到亞洲](docs/images/dark.jpg)

### 匯出、備份和匯入

目前的檢視可以匯出成 PNG 或 SVG，也可以複製 SVG 程式碼。底圖可以開關一級和二級行政區線、行政區名稱（字級 7–20 像素）、經緯網，以及東西德分界線和西柏林邊界；海洋、背景和未塗色國家的顏色都可以改。

配色的儲存方式要看用的是哪個版本：

- **網頁版**每次修改都會自動存進瀏覽器的本機儲存空間，但只在這一個瀏覽器裡，清除網站資料就沒了。要備份，就展開右下角的「配置 JSON（備份或導入）」，複製裡面的內容存成 `.json` 檔。還原時點「導入 .json 文件」，或者把內容貼回去後點「應用」。復原最多 60 步，重新整理頁面後清空。
- **桌面版**把配色存在你自己儲存的 `.json` 專案檔裡，「檔案」選單裡有新增、開啟、儲存、另存新檔和最近開啟。兩邊的格式相同，網頁版存下來的 `.json` 可以直接用桌面版開啟。

### 桌面版

桌面版是同一份頁面套上 Electron 外殼，可以完全離線使用：地圖資料、指令碼和字型都打包在程式裡，頁面有嚴格的內容安全政策，不會連上外網。macOS 上隱藏了系統標題列，視窗頂部那條顯示檔名，有未儲存的修改時會加一個 ●。

![macOS 桌面版](docs/images/desktop.jpg)

## 邊界設定

本專案不代表國際公認邊界，也不等同於任何一國的官方立場。

## 執行和建置

需要 Node.js（開發時用的是 24）、約 300MB 磁碟空間，第一次使用時依序執行：

```sh
npm install
npm run fetch          # 下載原始資料到 raw/，約 220MB
npm run prepare-data   # 產生中間檔案
npm run build          # 產生 dist/data 和 dist/index.html，約 20 秒
npm run serve          # 本機預覽：http://127.0.0.1:8765/wrap.html
```

只改了 `src/` 裡的檔案時，執行 `npm run assemble` 就夠了，它會同時產生網頁版和桌面版的頁面。改了資料處理規則，要從 `npm run build` 開始重跑。

桌面版：`npm run desktop` 直接啟動，`npm run dist:mac` 打包 Apple Silicon 版的 dmg 和 zip（各約 125MB，其中 50MB 是地圖資料），輸出到 `release/`。目前還沒有簽署和公證，複製到別的 Mac 上第一次開啟時，要按右鍵選擇「打開」，或者在「系統設定 › 隱私權與安全性」裡放行。

README 裡的截圖由 `node scripts/screenshots.mjs <globe|search|germany|blocs|dark>` 產生，需要先執行 `npm run serve`。桌面版那張是手動截的。

## 實作方式

地球用 WebGL2 和正射投影繪製，拖曳和靜止都是 1:10m 精度，三種拖曳情況都穩定在 60 幀；瀏覽器不支援 WebGL2 時退回 Canvas 2D。懸停醒目提示畫在一層 Canvas 2D 上，平面圖用 SVG 繪製，方便匯出。讀取資料、儲存檔案和讀寫設定都經過 `src/platform.js`，網頁版和桌面版各有一套實作。用到的函式庫有 D3 7.9.0、TopoJSON 和 earcut 2.2.4。

簡化後的國家輪廓直接嵌在頁面裡。1:10m 輪廓、行政區線，以及每個國家的一級（210 個檔案）和二級（201 個檔案）行政區資料是獨立的檔案，開啟對應國家時才載入，總共約 50MB。

資料用 mapshaper 處理，主要步驟是：

1. 以 Natural Earth 的國家資料為底，按自訂邊界合併或拆分部分單位，再扣掉跨國湖泊。
2. 用帶湖泊鏤空的一級行政區資料，按上面的設定重新分配歸屬，並用西柏林邊界把柏林切成兩半。
3. 德國的一級、二級行政區用 OpenHistoricalMap 的東德多邊形對齊（`scripts/gdr-align.mjs`）：每個行政區保留大部分面積所在的一側，貼著分界線、落在另一側的碎塊交給另一側共用邊界最長的鄰區。諾伊豪斯從二級資料裡切出來，在兩級裡都單獨成塊。
4. 二級行政區預設沿用資料本身的國家歸屬，只有邊界做過調整或分屬不同單位的地方，才按重疊面積重新判斷。原始資料的文字編碼是混雜的，名稱要逐條按 UTF-8 或 Latin-1 解碼。

WebGL 改造、桌面版、幀率測試和各版本的細節見[開發紀錄](docs/DEVLOG.md)（簡體中文）。

## 目錄

```
src/globe.html       頁面範本，__GEO__ 處會填入內嵌資料
src/globe-gl.js      WebGL 地球：球面三角化、著色器和繪製
src/platform.js      平台介面層：網頁版和桌面版的讀取資料、儲存檔案、讀寫設定
src/i18n.js          中英文介面文字
src/blocs.js         陣營和成員（截至 2026 年 11 月）
src/capitals.js      各單位的首都座標，由 scripts/capitals.mjs 產生
desktop/             Electron 外殼：main.mjs（主程序、選單、app:// 協定）、preload.cjs
design/logo/         標誌：產生指令碼、匯出指令碼、使用說明 GUIDE.md，成品在 kit/
docs/                開發紀錄和 README 截圖
scripts/             資料下載、處理、組裝、截圖和本機預覽指令碼
  fetch-data.sh        下載原始資料到 raw/
  prepare.sh           從原始資料產生中間檔案
  build.sh             產生 dist/data，並組裝出 dist/index.html
  capitals.mjs         從 Natural Earth 產生 src/capitals.js
  flags.mjs            把 flag-icons 的國旗按地圖單位打包成 dist/data/flags.json
  gdr-align.mjs        把德國行政區和東西德分界線對齊，切出諾伊豪斯
  assemble.mjs         組裝 dist/index.html 和 desktop/app/
  screenshots.mjs      產生 README 截圖
  serve.mjs            本機預覽
test/                用 puppeteer-core 驅動本機 Chrome 和 Electron 的測試
  interactions.mjs     塗色、代碼輸入、舊設定遷移
  denmark.mjs          平面圖插圖
  webgl.mjs            WebGL 顯示、點擊、懸停、縮放、匯出、陣營和中英文（分批執行）
  desktop.mjs          桌面版：專案檔、選單、匯出、內容安全政策
  bench.mjs            拖曳幀率
  mesh.mjs             在 Node 裡檢查球面三角化
```

`raw/`、`work/`、`dist/`、`release/` 和 `desktop/app/` 都是產生出來的，不放進 git。
